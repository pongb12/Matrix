# Matrix: branch restructure + caelestia-inspired rewrite

## Phase A — Git branch restructure (github.com/pongb12/Matrix)

Using `gh` (already authenticated as pongb12):

1. Create `dev` from current `main` (keeps history), push it.
2. Set `dev` as the default branch: `gh repo edit pongb12/Matrix --default-branch dev`.
3. Rename `main` → `test` (locally `git branch -m main test`, push `test`, delete remote `main`). The Mint/MATE version stays frozen on `test`.
4. Do all rewrite work on `dev`, push when done.

## Phase B — Rewrite on `dev` (caelestia-inspired, lightweight, multi-distro)

Decisions locked in: **lightweight stack** (Waybar/rofi/dunst/swaybg — no Quickshell), caelestia **look & structure**, rofi **menu** for Super+P, **Vietnamese** UI strings. Target: idle RAM ≈ 500–900MB on your N5030 / UHD 605 / 4GB.

### 1. New `scripts/multi-display.sh` — the headline feature
- Binds to `SUPER+P` (replaces the current `pseudo` binding).
- Enumerates outputs with `hyprctl monitors` (identifies the laptop panel as `eDP-*` and the projector/TV as HDMI/DP), falls back gracefully with a dunst notification if only one screen is found.
- Opens a rofi menu with 4 modes (Vietnamese labels + English descriptions):
  - **Chỉ màn hình máy tính** (PC screen only) — laptop on, external off.
  - **Nhân bản** (Duplicate) — `monitor=HDMI-A-1,preferred,0x0,1,mirror,eDP-1` for identical content, presentation-ready.
  - **Mở rộng** (Extend) — both screens enabled side-by-side; windows draggable between them.
  - **Chỉ màn hình thứ hai** (Second screen only) — laptop off, external on.
- Applies live via `hyprctl keyword monitor ...` and persists the chosen mode into a sourced `hypr/configs/displays.conf` so it survives reloads/relogin.

### 2. Hyprland configs (`hypr/`)
- `keybinds.conf`: add `bind = $mod, P, exec, ~/.config/hypr/scripts/multi-display.sh`; keep all existing keybinds.
- `appearance.conf`: caelestia-style rounded corners (~10px, 2px accent border) while keeping the hard performance rules — no blur, no shadows, fast 2–3 duration animations.
- `monitors.conf`: stays minimal/auto-detect; new `displays.conf` (sourced from `hyprland.conf`) holds the Super+P-selected state.
- `autostart.conf`, `env.conf`, `windowrules.conf`: minor polish, unchanged philosophy.

### 3. Caelestia-inspired theming (no weight added)
- `waybar/`: floating centered pill bar, rounded semi-transparent modules, caelestia-style dark palette (deep navy background, soft blue accent), cheap CSS hover — Vietnamese tooltips kept.
- `rofi/`: rounded launcher matching the bar, updated `colors.rasi` to the caelestia-style palette; also styles the Super+P mode picker.
- `dunst/`: notification style matched to the palette (used for display-mode feedback too).

### 4. Distro-agnostic installer (`install.sh` rewrite)
- Detects the package manager: on Arch/CachyOS offers to install all deps via `pacman` (hyprland, waybar, rofi-wayland, dunst, swaybg, kitty, brightnessctl, grim, slurp, wl-clipboard, thunar, pavucontrol, network-manager-applet); on anything else prints the dependency list and does a config-only deploy.
- Deploys configs (now including `scripts/` and `displays.conf`) into `~/.config/` — still idempotent and non-destructive, no more MATE-specific assumptions.

### 5. Docs rewrite
- `README.md`: reposition Matrix as a polished, distro-agnostic Hyprland rice (Arch, CachyOS, and any Hyprland-capable distro), remove the Mint/MATE framing, add: dependency table with pacman names, install instructions, full keybind table including Super+P, RAM budget table (expected idle ≈ 500–900MB with per-component estimates) and tuning knobs.
- `AGENT.md` / `DOC.md`: update context (dev = multi-distro release, test = Mint/MATE legacy), keep the banned-stack list, document the caelestia-inspired palette.
- `Struc.md`: regenerated to match the new tree. `TASK.md`: updated checklist.
